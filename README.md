My personal website :)

A single hand-written page: `index.html` and `style.css`, plus images and the CV in `assets/`. It deploys
to GitHub Pages from `main`, and `CNAME` points it at atharvaaalok.com.

To preview locally:

```bash
python3 -m http.server 8000
```

then open http://localhost:8000.
